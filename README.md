## 📖 Sobre o Projeto

O portfólio reúne informações sobre minha trajetória na Ciência da Computação, meus conhecimentos técnicos e experiências.

A interface foi desenvolvida com identidade visual em tons de roxo e layout responsivo, com navegação entre páginas e conteúdo em português e inglês.

---

## ✨ Funcionalidades Principais

- 🏠 **Página inicial:** apresentação pessoal, habilidades, interesses, curiosidades e certificados.
- 📄 **Currículo:** visualização e opção de download em PDF.
- 💻 **Projetos:** linha do tempo, imagens e links externos quando disponíveis.
- 🏆 **Experiências:** atividades acadêmicas e voluntárias.
- 📬 **Contato:** links para redes profissionais e formulário com nome, e-mail e mensagem.
- 🌎 **Idiomas:** alternância entre português e inglês por JavaScript.
- 📱 **Responsividade:** menu adaptado para dispositivos móveis.
- ✨ **Interatividade:** animações de destaque ao passar o mouse sobre elementos da interface.

**📌 Observação sobre o formulário de contato:** ao enviar, o site abre o aplicativo de e-mail configurado no dispositivo do visitante, com o assunto e a mensagem preenchidos. O envio só é concluído quando o visitante confirma no aplicativo. Não há serviço de envio automático nem armazenamento das mensagens.

## 📦 Dependências, Bibliotecas e Frameworks

O projeto **não utiliza frameworks JavaScript, bibliotecas de componentes ou dependências instaladas por npm**.

Não possui `package.json`, backend ou banco de dados.

As fontes são carregadas por meio de uma importação CSS do serviço externo Google Fonts. Para visualizá-las corretamente, é necessária conexão com a internet; caso contrário, o navegador utiliza as fontes alternativas definidas no CSS.

---

## 🏗️ Arquitetura

Aplicação web estática composta por cinco páginas HTML que compartilham os arquivos `style.css` e `script.js`.

As imagens e o currículo em PDF ficam na pasta `assets/`.

A navegação utiliza links entre as páginas, e as interações são executadas diretamente no navegador.

## 💻 Instalação e Execução Local

### 📋 Pré-requisitos

- Navegador atualizado (Chrome, Edge, Firefox ou similar).
- Visual Studio Code, recomendado para visualizar e editar o código.
- Extensão Live Server (opcional) para executar o site em um servidor local.

### ▶️ Passo a Passo

1. Baixe o repositório pelo botão **Code → Download ZIP** no GitHub ou clone-o com Git.
2. Extraia o ZIP, se necessário, e abra a pasta do projeto no VS Code.
3. Abra `index.html` no navegador. Alternativamente, clique com o botão direito no arquivo e selecione **Open with Live Server**, caso a extensão esteja instalada.
4. Utilize o menu superior para navegar pelas páginas.

**📌 Importante:** não é necessário executar `npm install`, configurar banco de dados ou iniciar um backend.
